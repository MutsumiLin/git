# 第一轮 AI 使用记录初稿

本项目使用 Codex 辅助需求分解、方案设计、编码、测试和文档编写。用户提供软件工程实验指导书并确定六人绿色出行积分系统，随后确认老师已同意六人组。本轮实际请求为依据既定分工制作第一轮迭代，并把代码按六个人拆分，供组员在 GitHub 上提交协作记录。此前也使用 Codex 读取指导书，形成六人实施手册和报告模板。

AI 本轮生成了 Spring Boot 身份权限、行程与积分、商品查询、Vue 用户端与后台、演示数据、测试、部署和 UML 初稿。为控制范围，商城兑换、核销、清算等内容保留在后续 Backlog；首轮界面不返回这些业务的虚构成功结果。方案中使用教学模拟碳系数，并保留 BigDecimal 精度、请求编号、事务、唯一键和规则快照。

本次工具验证包括真实 MySQL 与 H2 测试、前端测试和生产构建、HTTP 冒烟、后端重启、浏览器交互及模型语法检查。执行结果见测试记录。生成过程中修正了异常状态处理、并发查询、模块职责、模型语法和脚本参数等问题。以上属于本次辅助会话的基线工作，不等于六名成员已经分别完成了人工审查、修改或签字。

后续由各成员记录自己实际用了什么 Prompt、检查了哪些代码、采用或修改了什么、否决了什么以及为什么，再补充效率影响、遇到的错误和下一次使用策略。建议使用 AI 生成初稿和解释局部代码，由人决定规则、审查实现并亲自复现测试；不能只看界面正常就认定事务与权限正确。

实际 Prompt 示例一：请依据指导书，为六人碳中和主题的城市绿色出行积分系统详细分工，并逐步讲解如何实现。

实际 Prompt 示例二：现在制作第一轮迭代，分别提供每个人的最终代码，最后给六份代码用于 GitHub 提交。

组员各自的采用、修改、否决理由和人工验证结论：待实际完成后填写。互评和个人总结据真实工作记录形成。
