# 第二轮交付使用顺序

1. 先看docs/team/SPRINT2_ROLES.md，确定A至F固定职责。
2. 每人拿对应的第二轮增量包，放进已有第一轮仓库，文件按相同路径合并覆盖，其他文件保留。
3. 进入docs/members/sprint2看本人任务和提交清单。A分支feat/sprint2-a-platform，其他分支见docs/team/SPRINT2_GITHUB.md。
4. 全组六包合并后按deploy/SPRINT2_RUNBOOK.md升级启动。V1至V3不改，旧数据保留，自动新增V4/V5。
5. 六个增量包不是独立软件。完整集成源码包可单独启动核对，不替代六人的独立审查与提交。

第二轮已实现兑换、取消退分、库存管理、规则发布和核销初版；第三轮继续清算与统计；第四轮才是最终交付。
