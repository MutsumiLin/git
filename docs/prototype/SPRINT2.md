# 第二轮界面与人工演示

市民商城输入商品数量，显示确认单价和总积分；保存后显示成功订单，订单页提供随机核销码、取消确认和最终状态。积分账户按奖励、消费、退回显示正负变动。网络结果未知时以原编号恢复请求，禁止开启另一笔兑换覆盖待确认请求。

运营工作台提供商品维护与规则发布两个页签。商户工作台提供本店商品和订单核销两个页签；不展示其他商户数据。商品编辑表单包含SKU、名称、描述、分类、积分价格、库存和上下架状态；原SKU和所属商户不可变。浏览器截图见同目录sprint2。图中数据来自实际验证，不是初始化赠送余额。

后续清算和统计仍归第三轮，本轮没有这些功能的成功页面。本人验收与签字在对应成员第二轮说明中填写。
